# Roadmap

## Planned Features
- **Wi-Fi Direct P2P API Integration**: Transition from reliance on external Home AP routers to raw `WifiP2pManager` Direct bounds.
- **Chunked File Transfer Resume**: Implement local caching on partial transfers allowing paused downloads to resume without full byte loss.
- **Database Caching (Room)**: Storing transfer historical logs and trusted devices.
- **Roborazzi Screenshot Tests**: Guarantee UI parity between updates.
- **MVI Architecture**: Adopt MVI (Model-View-Intent) in Compose architectures to yield explicitly tracked uni-directional state behaviors.
